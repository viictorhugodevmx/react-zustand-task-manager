# Task Manager — React + Zustand Lab

Aplicación de gestión de tareas desarrollada como laboratorio
práctico para reforzar React y aprender Zustand desde cero.

## Objetivos

- Reforzar los fundamentos y patrones de React.
- Comprender el manejo de estado local y global.
- Aprender Zustand mediante stores, acciones y selectores.
- Implementar un CRUD completo de tareas.
- Practicar formularios controlados y validaciones manuales.
- Aplicar pruebas automatizadas durante el desarrollo.
- Construir una aplicación responsiva con CSS tradicional.

## Stack

- Node.js 22.19.0
- React 19
- Vite 8
- JavaScript y JSX
- Zustand (pendiente de integración)
- CSS tradicional
- Vitest
- React Testing Library
- Oxlint

## Funcionalidades previstas

- Crear, consultar, editar y eliminar tareas.
- Gestionar estados y prioridades.
- Buscar, filtrar y ordenar tareas.
- Visualizar estadísticas.
- Persistir tareas en almacenamiento local.
- Validar formularios manualmente.

## Metodología

Desarrollo progresivo mediante pasos y puntos.

Cada punto requiere validación antes de continuar.

Cada paso incluye sus pruebas correspondientes.

Al cerrar un paso se realiza un commit y push a GitHub.

Los archivos se crean y modifican desde terminal
utilizando comandos cat con heredoc.

## Ejecución local

Instalar dependencias:

npm install

Iniciar servidor:

npm run dev

Ejecutar pruebas:

npm test

Ejecutar análisis estático:

npm run lint

Generar build de producción:

npm run build
